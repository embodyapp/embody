## Independent review and hardening

An [independent initial review](./M07-review/initial-code-review.md) rejected the
first development snapshot: error-body ambiguity differed across surfaces, completion
failures could erase known results/IDs, and frame limits depended on chunk boundaries.
These were fixed and covered by parameterized HTTP/SSE/MCP regressions. Known results
now survive failed/bounded completion writes, with request IDs (including MCP success
metadata); the durable intent remains unknown on completion outage.

Additional coverage exercises a real PostgreSQL wire proxy dropping COMMIT ACK after
commit, SQL lock timeout/rollback/pool reuse, lease/window expiry without false success,
a separate process exiting after admission, and a real HTTP host committing a PostgreSQL
effect then dropping the response. The COMMIT fault exposed unhandled checked-out
`pg` client error events; the gateway now handles those without raw driver logging,
stale fallback or transaction replay.

Preflight cancellation/shutdown, late admission drain, stalled authoritative auth and
incoming body, and deadline-bound SSE backpressure are tested. Backpressure testing
also found and fixed a buffered terminal-frame continuation after deadline. IPv6
special-use aliases and bodyless/invalid status callbacks have regressions.
