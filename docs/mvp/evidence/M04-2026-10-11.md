## Implementation and scope decisions

- Distinct PostgreSQL platform database with maintenance-owned workspaces/apps/credential tables and restricted non-owner runtime DML. No automatic runtime migrations/bootstrap key.
- Memory and real PostgreSQL adapters share conformance. Workspace-row-locked transactions CAS every app/credential mutation; app revision, active release, promotion generation and workspace revision commit atomically. No lost revisions or partial duplicate-name/hash updates.
- M02 canonical workspace/app/release IDs; app identity is distinct from command namespace. Exact scoped role grant plus namespace action scope required. Same `kanban` name across workspaces does not imply shared endpoint or authority; per-workspace uniqueness prevents namespace ambiguity.
- Hosted `/w/<workspace>/...` routes only; existing reference routes remain for framework E2E. CLI catalog/stream URL joining preserves workspace/reverse-proxy prefixes (including trailing slash); MCP uses the full endpoint.
- Request-local ALS catalog/auth snapshot; **positive-cache capacity/TTL zero**, with per-operation authoritative reads and 5s DB pool/acquire/query/statement timeouts. Credential ID/revision/workspace bind MCP sessions; role changes cannot reuse old authority.
- Deploy-time stored manifests and active pointers, not heartbeat-derived discovery. Idle/ready/unavailable/disabled remain discoverable; deleted tombstones persist but are not discovered. Only idle/ready with an active release dispatch. Listing makes zero app requests.
- Live authentication before ETag/304; hosted metadata revalidation and Vary authorization. Store failures deny without stale fallback or internal error disclosure, even requested development mode. Liveness only is public.
- Trusted unavailable-discovery option cannot be injected through legacy registration payloads; reference heartbeat TTL semantics preserved.
- [Workspace/provisioning/credentials/routes/failure docs](../WORKSPACES.md); [reproducible test commands](../TESTING.md). No management/deployment controller, asymmetric host token, provider IAM, stateless MCP, durable audit/quota or hosted qualification claim (M05–M17).
