# Support

Embody is currently provided without warranties, service-level commitments, or guaranteed response times.

## Community help

- Ask usage and design questions in [GitHub Discussions](https://github.com/embodyapp/embody/discussions).
- Report reproducible defects with [GitHub Issues](https://github.com/embodyapp/embody/issues).
- Consult the [documentation hub](docs/README.md) and [troubleshooting guide](docs/production/02-troubleshooting-faq.md).

When requesting help, include the Embody package versions, Node.js version, storage backend, operating system, relevant configuration with secrets removed, and a minimal reproduction.

GitHub Issues are not a channel for security reports. Follow [SECURITY.md](SECURITY.md) for suspected vulnerabilities.

## Commercial support

No public commercial-support plan or SLA is currently offered. Unless a separate written agreement says otherwise, references to possible commercial support are descriptions of future product direction and are not commitments.
